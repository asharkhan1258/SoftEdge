SoftEdge Systems LLC — HTML / CSS / Bootstrap website

OPEN: Extract this ZIP and open / in a browser. All images, Bootstrap CSS and JavaScript are included locally; no build or installation is needed.

PAGES: Home, About Us, Services, Contact, Refund Policy, Privacy Policy, Terms & Conditions.

LANGUAGE: English throughout all pages, form labels, image descriptions and messages.

BEFORE LAUNCH:
1. Replace hello@softedge.example and +1 (202) 555-0123 in all HTML files and assets/js/main.js with real details. These are intentionally sample contacts.
2. The contact form opens an email draft, it does not submit to a backend. Connect a real form endpoint if direct submission is required.
3. Policy text is a starter draft. Confirm it against your actual practices, payment agreement and applicable requirements before launch.
4. Upload the folder contents to your static hosting account.
